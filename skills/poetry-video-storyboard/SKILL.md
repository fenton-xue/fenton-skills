# 古诗词视频分镜

将诗词转为“先生成稳定参考资产，再逐镜生成视频”的制作方案。优先保证可执行性、镜头一致性和后期配音对齐。

## 遵循用户当前阶段

- 用户只要求选诗时，仅给标题和理由，不提前输出全文或分镜。
- 用户已指定作品时，直接处理该作品。
- 用户要求修改已有文档时，在原文件上更新并保留用户确认过的内容。
- 信息足够时直接执行；仅在作品版本、画幅或平台限制会显著改变结果时提问。

## 工作流程

### 1. 确认文本与拆镜粒度

- 使用通行、可靠的原文版本；对版本有疑问时先核验。
- 默认按标点后的半句或短句拆镜，一条语义单位对应一个镜头。
- 保持原文顺序与标点，不为凑镜头数拆散固定语义。
- 中等篇幅优先控制在约 12–24 镜；过长作品先提出节选方案。

### 2. 规划参考资产

先识别贯穿多个镜头且需要稳定的元素：

- 有反复出镜的主人公时，始终创建人物定妆图提示词。
- 同一地点反复出现时，创建场景定妆图提示词。
- 风格或空间明显不同的场景分别创建参考图，例如人间庭院与幻想月宫。
- 一次性远景、抽象蒙太奇或无稳定主体的镜头通常不单独创建参考图。
- 用 A、B、C 编号，并为每张参考图写明用途。

人物定妆图应展示稳定的五官、发型、体态和完整服装。场景定妆图应展示固定的空间关系、建筑结构、光线方向、时代质感和色彩关系。

### 3. 编写参考图提示词

每条参考图提示词必须独立完整，包含：

1. 主体或场景的明确描述；
2. 历史时代与服装、建筑形制；
3. 构图、视角和光线；
4. 视觉媒介、色调、画幅与细节等级；
5. 排除项，如现代物品、错误建筑、文字、字幕和水印。

不要另设“统一视觉设定”章节。将必要的视觉规范写进每条参考图和视频提示词。

### 4. 编写逐镜视频提示词

先阅读 [prompt-patterns.md](references/prompt-patterns.md)，再生成分镜表。

每条视频提示词按以下顺序组织：

1. `根据给出的……参考图生成视频`，列出该镜实际需要上传的参考图；
2. 指定必须保持不变的对象，如人物、服饰、场景结构和光线方向；
3. 描述本镜发生的动作、环境变化与诗意表达；
4. 描述景别、机位、运镜、焦点和转场；
5. 在本条内写入视觉风格、色彩、画幅、画质和动作稳定性；
6. 写入与本镜相关的排除项。

引用人物定妆图后，使用“文士”“女子”“主人公”等稳定称谓，不再重复五官和服饰描述。引用场景图后，不再重复完整空间清单，只描述本镜涉及的区域和变化。

相邻镜头动作或空间连续时，加入“和上一镜头末帧”；独立蒙太奇、跨地点转场或时间跨度较大时不强行引用末帧。

### 5. 输出文档

默认生成 Markdown 文件，结构固定为：

1. 标题与作者；
2. `第一步：生成参考图`；
3. 每张参考图的名称、用途和完整提示词；
4. `第二步：逐镜生成视频`；
5. 两列表格：`原文`、`视频提示词`；
6. 简短使用说明，注明每镜应上传的参考图和末帧策略。

除非用户明确要求，不增加释义、赏析、制作过程记录或全局视觉设定。

## 配音与时长

- 默认建议先生成无对白视频，再统一制作朗诵和配乐，以避免多次生成造成音色、语速和情绪漂移。
- 用户要求配音同步时，先得到整首成品朗诵，再按音频中每句的实际起止时间确定镜头长度。
- 允许画面比诗句提前约 0.2–0.4 秒进入，并在朗诵结束后保留短暂余韵；以自然听感为准。
- 平台单镜时长不足时，将较长诗句拆为两个语义连续镜头，或使用慢动作、停留与镜头延展，不压缩朗诵。
- 用户要求表格包含时长时，增加 `建议时长` 或 `配音时间码` 列；否则保持两列。

## 质量检查

交付前逐项检查：

- 原文无漏句、错字、乱序或标点误拆；
- 每个反复出现的人物和关键场景都有参考资产；
- 每条分镜明确说明应引用哪些参考图；
- 分镜未重复参考图已经固定的人物外貌与完整服饰；
- 每条提示词均包含本镜所需的风格、画幅、画质和排除项；
- 运镜能够在合理的单镜时长内完成；
- 动作、月光方向、时间推进和相邻镜头衔接合理；
- 输出中没有独立的“统一视觉设定”。
