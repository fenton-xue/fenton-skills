## 〇、总原则（所有决策之上）

### 0.1 正确的时候做正确的事

**【Chris说过】**（`1.【前言】如何学习曼森模型？.md`）
- 技术流重点：**正确的时候做正确的事**  
- 正确的时候 = 当前关系阶段（前/中/后）  
- 正确的事 = 该阶段可用的技术点  
- 无阶段蓝图 → 技术用错阶段 → 无结果  

### 0.2 阶段错配的三类致命错误

**【Chris说过】**（`1`）

| 错误 | 表现 | 后果 |
|---|---|---|
| 前期做中后期 | 未上钩就叙事/滔滔讲自己是谁 | 像自我证明、低价值、边界消失 |
| 中后期只会前期 | 只会推拉挑战制造张力，不会服从性/舒适/收尾 | 有兴趣但搞砸 |
| 误判后退 | 已过前期却当吸引力不够，退回只做吸引 | 关系推不动 |

**经典反例（Chris 学员）**：搭讪被拒 → 归因「她不知道我是谁」→ 狂讲故事 → 女人无窗口。

### 0.3 底层权利结构（影响所有决策）

**【Chris说过】**（`2.【前言】关于曼森三阶段（M1-M3）蓝图.md`）
- 女人 = **性的守门员**（最终决定谁能上她）  
- 男人 = **关系的守门员**（决定谁进入你的生活/关系）  
- 贝塔放弃关系守门权 → 只能被女人选择  
- 转盘子/多选 = 握住关系守门权的心态落地  
- 天生好手说「最终都是女人选」：对一半——未到高阶选择者阶段时你仍是被选；但男人仍有关系选择权制衡  

### 0.4 关系进展的度量（禁止用错尺子）

**【Chris说过】**（`2`）
- **不用时间衡量**阶段  
- 反例：相处 1–2 月、上百小时仍可能在前期（女人仍在筛选/挑刺）  
- 关键指标：  
  - M1 通过 ≈ **上钩**  
  - 进入 M2 ≈ **服从性出现**  
  - M2 核心工作 = **服从性积累**（不是继续测「她有没有兴趣」）  
  - M3 核心 = **共赢框架 + 收尾**

## 一、曼森三阶段完整结构（M1 / M2 / M3）

### 1.1 M1 前期 = 筛选阶段

**【Chris说过】**（`2`）

**女人侧**
- 高傲/刁难/废测 = 筛选框架，挡掉贝塔软男  
- 目标：判断你是否「够格」→ 够格 ≠ 已喜欢，是有基本好感、有资格进后面  

**男人侧（学了 game）**
- 同样傲慢筛选：她是不是够格女人  
- 挑战/推拉 = 给女人废测、建立你是买家  
- 双向筛选  

**通过指标**
1. **上钩**：好奇、反应、进入你节奏（不合格男人是空气）  
2. 上钩前：可能经历主/被动废测，必须撑过  

**时间**
- 无固定分钟数；可能 1–2 分钟也可能 10 分钟+  

**M1 技术包（实操篇实际覆盖）**
- 推拉、挑战、上钩点识别、自我赋格制造、转场坚持、破防、随机性、废测破解  

### 1.2 M2 中期 = 服从性与投入阶段

**【Chris说过】**（`2` `12` `15` `16`）

**进入标志**
- 女人开始愿意给服从性  

**核心任务**
- **服从性积累** = 实质情感投入（不是只测兴趣）  
- 对比贝塔恋爱：女人积累男人的服从性（接送、饭票、跑腿）→ 学了 game 要反过来积累**她的**服从性  

**同时出现**
- 开始赋格认可（不再只筛选）  
- 叙事与深入了解  
- 肢体/情绪/话题升级  
- 后续聊天邀约、快速升级（场景依赖）  

**M2 技术包**
- 后续聊天、学员聊天框架、快速升级、服从性积累、约会升级（肢体氛围 + 性话题）  

### 1.3 M3 后期 = 共赢与收尾

**【Chris说过】**（`2` `18` `19` `20` `21`）

**前提问题**
- 她喜欢你却不上床，常见逻辑：上完她会**输**、你单赢  

**任务**
- 建**共赢框架**（剧本游戏等在其他板块；本实操以叙事协作框架+收尾操作为主）  
- 逻辑上消掉「不上床」的理由  
- 转私密空间 + 收尾  

**M3 技术包**
- 叙事（筛类型 / 输价值观成理想型）  
- 收尾1：抗拒时进私密空间  
- 收尾2：排除闺蜜阻碍

## 二、各技术：触发 / 执行 / 失败 / 决策树

### 2.1 推拉

**触发【Chris说过】**（`3`）
- 全程尤其 M1；多人局、注意力管理、女人挑战你时  
- 目的优先：**强化选择者/买家/奖品框架**，其次才是情绪  

**执行要点**
- 语言推 + 行为/态度/注意力推  
- 推可多于拉  
- 假性失格（「三大讨人厌星座我也是」）  
- 闺蜜 game 分散注意  
- 慢、不饥渴坐旁边（「迫不得已/换风水」）  

**何时少用/不用【推断+原文边界】**
- 全文强调推拉服务框架；若已在强舒适/共赢收尾且张力过高需协作时，纯推可能破坏共赢（【推断】）  
- 无选择者底层时，硬推会空/假（【Chris】推的力量来自有其他选择）  

**失败模式**
- 只当情绪技巧，无框架  
- 挑战点打不中 → 女人逻辑冷回  
- 全程紧绷无平聊 → 怪  

**决策树**
```
需要强化买家感/降投入? → 推（注意/语言/态度）
女人挑战你? → 推回去或挑战回去（内化反应）
情绪掉了? → 推拉重启张力
只想逗乐无框架? → 无效推拉（失败）
```

### 2.2 挑战

**触发【Chris说过】**（`4`）
- M1 建立男女框架与性张力的**必要条件**  
- 刚搭讪、第一次见面前期、平聊过久需重启  

**执行要点**
- 设立基准线打量：你够不够格  
- 完整表达挑战意思；框架博弈时**不进她框架**  
- 可只给主观感受/事实，不解释  
- 女人求认可时继续筛选，前期不急正赋格  
- 可复用同一标签挑战（如「销售」贯穿现场到微信）  

**失败模式**
- 无挑战 → 聊天太平 → 无吸引  
- 解释过多 → 框架变低  
- 中后期技巧无效常因前期未让她进框架（`4`）  

**决策树**
```
前期需要性张力/筛选? → 挑战
她争辩定义（南/北等）? → 坚持你的标准维度，不跟她地理抬杠
她自我赋格? → 继续打量；可轻推；暂缓全盘认可
她踢回挑战? → 接住踢球，放大张力（好事）
```

### 2.3 上钩点（识别与节奏）

**触发**：任何接近打开后 15–30 秒关键窗（`5`）

**上钩信号【Chris说过】**
1. 表情/情绪反应（笑）  
2. 被你节奏带领  
3. 停下原事给注意力  
4. 好奇提问  
5. 脚停进入对话  
6. 夜场：眼神 2–3 秒可先钩  

**未上钩时**
- 输出频率必须高，断线易 game over  
- 加强意图眼神、男女框架前提、信任  

**已上钩后**
- 可降输出；可沉默；可转场评估  
- 目的从「要号」转为「进入对话/约会」  

**决策树**
```
脚在退/回避/注意不在你? → 未上钩：加压流畅输出+框架
出现笑/停脚/提问/跟随? → 上钩：放慢，找计划窗口
问「你去哪/有事吗」? → 转场/邀约窗口
```

### 2.4 自我赋格（制造她证明自己）

**触发【Chris说过】**（`7`）
- M1 要制造：她求你认可/关注 → 中后期才持续投入  

**执行**
- 选择者筛选框架 + 挑战标签（工科女/气质/肤色）  
- 她证明后**不轻易认可**  
- 真·自我赋格 = 进入你「够格」标准去证明，而非随便解释一句  

**失败**
- 太快赋格认可 → 失去筛选动态  
- 无标签/无标准 → 她无处证明  

**决策树**
```
需要她投入/求认可? → 设标准并挑战缺口
她展示证明? → 暂缓全盘认可；可再测
已过筛选进中期? → 可开始正赋格给舒适（见升级篇）
```

### 2.5 转场坚持点

**触发【Chris说过】**（`8`）
- 上钩后有窗口：无事找酒馆、脚不走、聊得下去  

**执行**
- 无事：直接「一起坐会儿」  
- 有事/拒绝：看脚；2–3 次坚持  
- 逻辑：不打乱她原计划（明天下午走→今晚可坐）  
- 可加轻挑战邀约  

**何时停【推断+案例】**
- 脚走、完全无窗口、逻辑上会打乱硬计划且她坚决 → 转播种后续（对比 `9` 夜晚等闺蜜时选择播种而非死缠即时）  

**决策树**
```
有明确计划空隙/脚停? → 提出转场
拒绝但脚不动/继续聊? → 再邀+逻辑消除顾虑
窗口弱但环境不适合即时? → 播种模糊邀约+加联系
```

### 2.6 破防

**触发**：白天搭讪、女人在自己事框架里（等人/赶路）（`9`）

**执行三件套【Chris】**
1. 男女框架（可激进开场，不进则改）  
2. 背景介绍 = 正常人  
3. 信任感 + **意图不藏**（「然后呢」时正面说觉得好看+推拉）  

**失败**
- 隐藏意图、怂、奇怪无背景 → 无效搭讪

### 2.7 随机性

**触发【Chris说过】**（`10`）
- 白天、书店/校园/办公区、偏内向传统女（约 60%）  
- 夜店/高能场**不必**  

**执行**
- 间接礼貌打开 → 假性时间限制 → 合理化出现 → 再渗 game  
- 目的：先进入长对话练习场；降低蓄意感与需求感  

**失败**
- 情景外硬搭 → 像职业搭讪者  
- 新手跳过这层直接话术 → 秒拒、练不成

### 2.8 废物测试

**触发**：M1 全程；微信后续极常见（`11`）

**女人逻辑【Chris】**
- 测你是否一致、是否真像表现的那么屌  
- 试图破坏你刚建的框架  

**破解核心【Chris】**
1. 回应这一句  
2. **维持先前框架一致性**（更重要）  
→ 常达成「互相筛选」协作，而非跪选或纯杠  

**窗口**：破测后立刻出现  

**失败**
- 变急切追问何时能来 → 与选择者不一致  
- 只顾自己框架忽略她的表达逻辑  

**决策树**
```
废测来了?
├─ 她要你证明自己（选择者姿态）→ 协作：你也筛她，出来互相验证
├─ 她攻击你的标签/挑战 → 拉或重构，但不弃选择者
└─ 破测后 → 具体化邀约，但保持慢/可改天
```

### 2.9 后续聊天 / 邀约

**触发**：有联系方式后的 M1 末–M2（`12` `13`）

**规则【Chris】**
- 舒适闲聊可以有，**不能只有**  
- 目的性要强：男人时间贵  
- 推开式邀约 > 乞求式  
- 已有深度约会后可多给真实信息建舒适；未见面则控信息  
- 新手尽量约到**你的场**，避免去她场变工具人  
- 邀约可加前提框架（「前提你说的是真的」）  

**失败**
- 纯寒暄 → 注意力廉价 → 后续 game 失效  
- 女邀旅游陪玩就去 → 导游/拎包  
- 线上框架对、线下塌回平聊 → 无结果

### 2.10 快速升级（夜店路径）

**触发【Chris】**（`14`）：夜店/酒吧，时间充裕、社交状态开  

**执行链**
打开谈话 → 接她的 game 踢球 → 筛选框架（打分等）→ 服从性测试（叫哥哥等）→ 赋格舒适 → 角色扮演调情 → **坚持你的升级框架** → 高压/可走感 → 吻 → 转场前先加微信  

**何时不用完整叙事**
- 夜店噪音/节奏：叙事舒适感可后置或减少  

**白天约会差异【Chris】**
- 升级往往更靠后；中期更重叙事价值观与框架

### 2.11 服从性积累

**触发【Chris】**（`15`）：前中期；她对你有需求时；1v1  

**执行**
- 角色扮演框架（玩笑化）  
- 需求交换：送回家/WiFi 等换服从性（叫称呼、亲、坐腿）  
- 语言升级同步肢体  
- 判断：情绪正面即可推进，不要求嘴上答应  

**何时不做**
- 多人局实质升级（社交压力）（`15`）  
- 客观硬限制 + 强执意抗拒 → 保后续不强攻  

**原理【Chris】**
- 小服从都没有 → 床上大服从难  
- 大服从之后小服从很容易

### 2.12 约会升级（肢体氛围 + 性话题）

**触发**：第二次及以后约会，已有 M1 吸引（`16` `17`）

**肢体/氛围【Chris】**
- 心态：她是女友；你是领导者 → 命令式靠近（坐过来）  
- 挑战变「家长管」我们框架  
- 自在感：性自然、可低俗玩笑  
- 氛围目标：旁人看来是情侣  

**话题升级【Chris】**
- 先氛围到位再聊第一次/癖好  
- 你先坦然打开性话题  
- 用叙事画面植入「跟你做爱会怎样」  
- 她短期注意力强 → 讲短期故事/共识；不必硬拗观点型长期框架  

**失败**
- 中后期仍「网友距离」无氛围  
- 自己对性羞愧 → 她感觉你匮乏  
- 进她升级框架（她的称呼/规则）→ 她变选择者、废测增多

### 2.13 叙事（上：筛关注点 / 下：输价值观）

**触发【Chris】**（`17` `18` `19`）
- **中后期**；有吸引之后  
- 前期讲 = 自我赋格感  

**目的**
1. 立体形象 A→B（过去经历 → 现在的你）  
2. 舒适感/共赢前提（她抓住你、不觉得会输）  
3. 输出价值观，成为可协作的「理想型」  
4. 可选 A→B→C 画未来（长期）  

**流程决策树**
```
已有吸引?
│否 → 禁止深叙事
│是
▼
筛信息（情史、分手原因、对控制/结婚态度）
▼
判断注意力：长期 / 短期 / 传统开放?
▼
编排故事方向（同经历可切长/短框架）
▼
观察她问什么（问上一段→偏长期等）
▼
建立协作中期框架（不单赢长期供养，也不无差别极端吓跑）
▼
赋格认可 + 保留轻挑战（防舒适过度杀吸引）
▼
展示可控缺点 → 可得性
▼
播种下次 + 2:3 投入原则
```

**类型策略【Chris】**
- **偏长期**：可接受中期「走一步看一步」；讲筛掉「太保守」的故事防被锁死结婚框架；仍保留真实短期面，防假君子警报  
- **偏短期**：少观点说教，多经历共识、性话题、刺激叙事  
- **永远不要**：无差别灌故事；完全放弃自己框架去讨好她的类型  

**失败**
- 不知道讲什么 / 乱讲  
- 顺着她完全变长期供养  
- 过早完美人设 → 无可得性

### 2.14 收尾（进私密空间）

**触发**：升级与舒适足够，向私密移动（`20` `21`）

**规则【Chris】**
1. 私密空间 = **行程节点不是终点**（「歇会儿喝热水，我再去找朋友」）  
2. 给**偶然性台阶**（她怕显得随便）  
3. 强势带领，不是纯骗术话术  
4. 做**问题解决者**：房卡、闺蜜、时间、安全顾虑提前清

**线上不讲**：进门后最后一分钟抵抗的具体操作（只线下）

## 五、M1→M3「学习决策」建议（Chris 教学优先级）

**【Chris说过】串联**

1. **先有阶段蓝图**（`1` `2`）——否则技术越学越错位  
2. **先能进对话**（破防/随机性）（`9` `10`）——否则 game 无处施展  
3. **练挑战+推拉+废测** 做出选择者动态与上钩（`3` `4` `11`）  
4. **会读钩与窗口** 才能转场（`5` `8`）  
5. **后续用框架邀约**，避免工具人（`12` `13`）  
6. **中期服从性积累+升级**，关系才前进（`15` `16` `17`）  
7. **叙事按类型协作**，为共赢铺路（`18` `19`）  
8. **收尾领导者解决问题**（`20` `21`）  
9. **必须实践**（`2` 结尾）——只看无进步  

**【推断】** 课程顺序本身就是学习决策树：M1 技术密度最高，因所有中后期建立在前期框架上。

## 六、完整决策树（实战一页纸）

```

白天内向情景? --是--> 随机性间接打开

              --是--> 进入对话节奏放慢

【转场/联系】
有即时窗口? --是--> 转场（拒绝看脚，坚持2-3）
          --否--> 播种邀约 / 加联系
微信废测? --> 同M1破解；推开式邀约

【M2】
服从性有了吗? --否--> 继续吸引筛选，查是否假上钩
            --是--> 服从性积累（角色扮演/需求交换）
场景夜店? --> 快升级链
场景约会? --> 氛围命令靠近 + 适量叙事 + 性话题
多人? --> 不做实质升级

【类型】
聊经历看注意力长/短

舒适↑但保留轻挑战

【M3 收尾】
共赢/可得性够?
转私密：节点理由 + 偶然台阶
有阻碍（闺蜜/房卡/时间）? --> 领导者先解决
门口抵抗? --> 降阶外坐再节点化
进门后操作 --> （课程：仅线下）
```
