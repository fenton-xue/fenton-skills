## 二、自创/核心术语与概念定义

> 以下定义严格按基础篇用法还原。【推断】仅用于补全体系位置，不冒充 Chris 定义句。

### 2.1 雄性极性 / 雄性急性 / 雄性即性 / 雄性激性
- **【原话】** 男人与生俱来的磁极；只要是男人就拥有；非金钱长相地位特权。
- **功能**：站着就能吸引；内核六感之后的心态补充（Chris 自述对 1.0 内核的补充）。
- **对立面**：负极性压抑；女性化表达；社会化阉割。
- **【推断】** 基础篇把「极性」操作化为：身体强壮 + 简单男性框架 + 耐测 + 不惧「拒绝」+ 不自我设限分数。

### 2.2 吸引（Attraction）
- **定义（Chris）**：本能的磁极相吸；繁衍/交配导向；非逻辑评价「优秀」。
- **不是什么**：非 Game 技巧产物；非外貌金钱地位产物（那些只提概率与流畅度）。
- **唯一建立方式（黄金二）**：忍受并扛过废物测试。

### 2.3 废物测试（Shit Test）
- **定义**：女人在上床前刁难、侮辱、忽略、拒绝式试探，检视你是否够格、是否在压力下仍保持自我。
- **Chris 态度**：「太棒了」——考验越多上床越快；想上你才会测。
- **两类**：
  1. **主动测试**：语言挑衅——矮、普信、屌丝等，试图摧毁框架，让你像回妈妈怀里痛哭的孩子。
  2. **被动测试**（常被忽略，含 PUA 同行）：无视、怪表情、白眼、臭脸；含「婊子防护罩」。
- **失败信号**：退缩、垂头丧气离开 → 她知道你不行 → 等同「交流上提前阳痿」。

### 2.4 婊子防护罩
- **定义**：女人前期冷漠/臭脸的被动废物测试形态。
- **作用**：吓退在意反馈、把冷脸当拒绝的男人；学电前期卡关主因。

### 2.5 框架（Frame）
- **定义**：个人/团体理解特定事物的解释系统；传递心态与行为背后的潜在心理；看待世界的行动方针与坚持。
- **人人皆有框架**。
- **二分**：
  - **内部框架 / 预设框架**：开场前已设定的自我叙事（如「我是男人所以会操女人」vs「我是尊重女人的好男人」）。

## 四、说服术 / 框架控制完整体系

### 4.1 总论：洗脑课定位
- **【原话】** 说服术章节自称「洗脑课程」，主讲框架运用；框架是 game 最重要概念之一。
- **目标**：让他人迎合你的观点与立场，进入你的框架；最终精髓是共赢协作式框架，而非单纯战胜。

### 4.2 内部框架（预设）——先于技术
| 预设 | 行为后果 | 女方读法 |
|------|----------|----------|
| 我是尊重女人的好男人 | 护送回家、盖被、不动她、引以为傲 | 你不是男人；可无偿索取 |

**关键原理句**：女人要求保护尤其生命安危时，正常应贡献性作为交换；软男框架否定了自己是男人，故交换被取消。

### 4.3 外部框架技术阶梯

#### 层级 0：框架感来源
- 来自预设信念的一致性；行为与框架一致才不被反噬。
- 软男欲望与「好男人」框架冲突时，会遭女人强烈谴责：「你不该这样，你不尊重我」= 潜台词你已默认无偿付出。

#### 层级 1：框架控制（防御·入门）
**何时用**：  
1. 她提出要求  
2. 她提出反对意见  
3. 她明显冒犯你/做你讨厌的事  

**示例（原文）**

| 场景 | 她 | 你（框架控制） |
|------|----|----------------|
| 要求 | 开车来接我们 | 我们才刚认识，不是吗？ |
| 要求 | 你做什么工作？ | 一般情况下不告诉别人，讨厌工作之余谈工作 |
| 要求+交换 | 买冰淇淋给我 | 可以，但加附加条件（价值交换） |
| 反对 | 咖啡没意思，去蹦迪 | 一般不和刚认识的人蹦迪；可以，但先喝完咖啡再决定 |
| 冒犯/讨厌 | 喋喋不休无营养 | 有趣但我一点不感兴趣，请不要继续 |
| 冒犯 | 当着你面抽烟/拿你杯子 | 不喜欢别人在我面前抽烟；未经允许不要用我的东西 |

**效果**：树立原则与边界；站在主动权位置；「先证明你值得我投入更多」。  
**警告**：勿成框架控制狂；可按客观情况微调（如她明早要走可选择去接）。

#### 层级 2：框架强化
- **条件**：你 100% 认为自己是对的；尤其**基于事实**的问题。  
- **方法**：不做辩解，只强化原框架。  
- **例**：  
  - 街头认识很奇怪 → 这很正常有什么奇怪  
  - 接吻太快 → 有什么快？很正常  
  - 我是男人，意图就是男人对女人的意图 → 事实，无需解释  
- **局限**：三观/观念战上过度强化 → 像蛮不讲理的流氓恶霸，无法说服。

#### 层级 3：框架延伸 / 框架重塑
- **原理**：对方与你相左时，在原框架上延伸新含义，重构后把双方覆盖进同一框架。  
- **例**：  
  - 你：喜欢会做饭的女人 / 她：几乎不做饭 → 重塑为「愿为喜欢的人付出；我不会但愿意为所爱去做」  
  - 你：喜欢运动的女人 / 她：很少运动 → 重塑为「关注自律；连生活都掌控不了如何控制情感」  
- **定位**：比强化更有策略性；通向更高级洗脑技术的基础。

#### 层级 4：格斗家框架
- **原理**：接受框架对抗，但回避对她有利的规则，改用你擅长的规则（拼不过拳就用脚；刀不行就上枪）。  
- **例**：  
  - 她：日本料理世界最好吃 → 你：菜系不重要，重要是厨师技术  
  - 她：不给女人花钱就是不爱 → 你：爱不能只用钱衡量，重点是关键时刻挺身而出（重点可替换为任何你擅长维度，如能否接受过去等）

#### 层级 5：审判长框架
- **原理**：在现有议题上赋予更高道德与价值观，占领制高点，重新定义对错；掌握对错定义权。  
- **Chris 指出**：女人最爱用；羞辱性策略底层常是审判长；双标女权常用；驯化男人=由女人定义对错，符合其利益=对，再披道德/爱情外衣。  
- **反制例**：  
  - 她：不给看手机=不信任 → 你：不是信任问题，是原则问题  
  - 她：男人就该买单，不买单算什么男人 → 你：提倡男女平等；不是难不难人，是公平公正  
- **弱点（Chris）**：女人往往缺真正立场；你先占更高点她难反驳；「女人其实都很蠢/脑袋里都是屎」——原话级贬抑。  
- **终招**：无计可施 → 歇斯底里 + 性别挡箭牌 + 情绪打逻辑；称有对治但本节不展开。

#### 层级 6：哲学家框架（Chris 自称 game 中最长使用）
- **原理**：用抽象笼统概念替代具象事物；符合中庸、模棱两可；消解绝对对错；具象框架易被推翻。  
- **例**：  
  - 有过一夜情吗？→ 取决于如何定义；人人有失败经历及时止损，若这叫一夜情那我想我有  
  - 你是渣男吗？→ 取决于如何定义；对不喜欢的人冷酷绝情若叫渣，也许我是  
  - 社会辩论「外地人抢饭碗」：可从历史游牧/谁非外地人说；反方也可从底层内卷无谈判筹码说——正反都能圆  
- **延伸价值**：约会以外的日常交流、公众人物措辞、避免成为众矢之的。

#### 层级 7：精髓——混合型双赢框架
- 好框架=双赢协作，不是你输我赢。  
- 无人愿接受强加观点；次次要赢 → 可能赢框架输更多。  
- 高手框架混合，让对方总找到符合自己立场的点 → 自愿参与共赢框架。  
- **【原话】** 此为曼森方法洗脑术精髓；掌握则成真正 game 高手。

## 七、内在矛盾或张力

> 本节区分：**Chris 自己承认的张力** vs **【推断】文本间紧张关系**。

### 7.1 Chris 明确处理过的张力

| 张力 | 处理方式 |
|------|----------|
| 过去教 Alpha/Beta vs 现在说忘掉 | 标签仅便于理解现象；长期维持最强 Alpha 有害 |

### 7.2 【推断】未完全消解的张力

1. **「天生就会 / 只需是男人」 vs 「必须自我洗脑、过滤反证、实践循环」**  
   - 一边说吸引是本能、孤岛必成；一边说必须无条件相信、重复新谎言、主动过滤不符合五法则的现实反馈。  
   - Chris 用「社会谎言先洗脑了你，所以要用新洗脑唤醒天性」缝合，但方法论上仍是高度建构的信念工程，与「无学习的本能」并置。

2. **「不必 Alpha / 不要比较」 vs 大量比较性话术与鄙视链**  
   - 明确反对与他人比谁更 Alpha，但课文持续使用软男/龟男/Beta/娘们/天生好手等层级标签，学员仍易滑回比较框架。

3. **「拒绝不存在/是害怕你」的普遍化 vs 现实中真拒绝与无兴趣**  
   - 深层心态模型强力重释一切冷反馈；同时承认技巧与辅助因素影响成功率。若一切冷脸都是怕你，失败归因容易全部内收到「框架不够」——这是赋能也是封闭解释体系。

4. **女人是儿童（需领导保护） vs 保护应以性交换 / 渣男少付出**  
   - 儿童模型要求男人当成年人领导；交换模型要求保护绑定性回报、并欣赏低付出高效上床。  
   - 道德语言被剥离后，内部逻辑可自洽（领导≠无偿保姆），但对「照顾责任」边界基础篇未细定。

5. **「原始吸引只靠强壮+耐测」 vs 哲学家/审判长等高度语言策略**  
   - 心态篇贬低操控技巧；说服篇系统教授洗脑级框架术。  
   - 【推断】Chris 的分层是：技巧不创造极性，但框架技术在互动中防守与导向；然「洗脑术精髓」的措辞仍使「非操控」叙事紧张。

6. **「女人更蠢/脑袋是屎/无立场」 vs 「女人最爱用审判长且善于驯化」**  
   - 同时断言认知低幼与策略性道德操控高明；可能意指「短线策略本能强、长线抽象立场弱」，但未明说。

7. **双赢框架 vs 支配儿童**  
   - 说服五强调双赢混合框架；女性心理强调支配、发号施令、不妥协。  
   - 【推断】可能场景分化：话术层协作感 vs 关系位阶层父权领导；基础篇未显式划分。

8. **「高分低分本质一样」 vs 仍使用四分/九分语言与「配得感」问题**  
   - 用分数语言取消分数本质，教学上有效，概念上自指紧张。

9. **曼森（查尔斯）案例**
