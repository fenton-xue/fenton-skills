# 字段契约

第一段输出的 JSON 数组，每个元素必须包含以下 14 个键（名称与飞书表头完全一致，括号全角半角均可识别）。

| 字段 | JSON 类型 | 飞书单元格 | 说明 |
| --- | --- | --- | --- |
| 小红书昵称 | string | 文本 | |
| ID | string | 文本 | 小红书号，必须是字符串，避免长数字丢精度 |
| 粉丝量（W） | number | 数字 | 单位万，如 `12.3` |
| 类型 | string | 文本 | 博主类型/分级，如「腰部」 |
| 主页链接 | string | 超链接 | |
| 发布链接 | string | 超链接 | **去重键**，必须唯一且非空 |
| 发布时间 | string | 文本 | 统一 `YYYY-MM-DD HH:MM` |
| 曝光量 | integer / null | 数字 | 取不到时给 `null`，写入为空白 |
| 阅读量 | integer / null | 数字 | 同上 |
| 点赞 | integer / null | 数字 | 同上 |
| 收藏 | integer / null | 数字 | 同上 |
| 评论 | integer / null | 数字 | 同上 |
| 转发 | integer / null | 数字 | 同上 |
| 总互动 | integer / null | 数字 | 由接口返回，脚本不重算 |

数值字段允许带千分位逗号的字符串（`"1,234"`），脚本会转成数字；无法解析会报错并指出第几条、哪个字段。

## 示例

```json
[
  {
    "小红书昵称": "示例博主A",
    "ID": "123456789",
    "粉丝量（W）": 12.3,
    "类型": "腰部",
    "主页链接": "https://www.xiaohongshu.com/user/profile/aaaa",
    "发布链接": "https://www.xiaohongshu.com/explore/note0001",
    "发布时间": "2026-11-10 20:15",
    "曝光量": 52000,
    "阅读量": 31000,
    "点赞": 1800,
    "收藏": 900,
    "评论": 120,
    "转发": 60,
    "总互动": 2880
  }
]
```
