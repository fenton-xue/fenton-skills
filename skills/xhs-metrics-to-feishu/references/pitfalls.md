## 一、接口与脚本

### P1. values_append 报 90202（已修复）

| 项目 | 内容 |
| --- | --- |
| 现象 | 首次真实写入失败：`POST .../values_append -> code=90202 msg=range in request is wrong, rows of value:3 > range` |
| 原因 | 首稿用 `A1:N1`（1 行）作为 range 追加 3 行；真实接口要求 range 的行数不小于待写入行数 |
| 修复 | `scripts/feishu_sheet.py` 追加时 range 改为 `{sheet}!A1:{末列}{本批行数}`，追加位置仍是表尾 |
| 为什么没提前发现 | 首稿的假飞书服务按「想当然」的规则实现，没有这条校验，15 项测试全过但不代表真实行为 |
| 防再犯 | 假服务 `tests/e2e_fake_feishu.py` 已补上同样的校验；新接口先 `--dry-run`，再用 1–3 行真实写入验证，最后才放量 |

### P2. 表格 token 不是浏览器地址里那一串（已绕过）

| 项目 | 内容 |
| --- | --- |
| 现象 | 新建表格后地址是 `/wiki/GRwcw7AlMi6I3KkJfeScosOFnVc`，页面源码里搜不到任何 `sht...` 形式的 token |
| 原因 | 「新建」默认把表格放进「我的文档库」知识库，地址里是知识库节点 token；表格自身 token（本例 `OA6Ss...`）不带 `sht` 前缀 |
| 处理 | 在该页面内用登录会话请求 `/space/api/wiki/v2/tree/get_node/?wiki_token=<节点>`，返回 `data.obj_token`，`obj_type=3` 即电子表格 |
| 注意 | 脚本支持传 `/wiki/` 链接，但那条路走开放平台接口，需要 `wiki:wiki:readonly` 且重新发布；本次未开通，因此未验证 |
| 注意 | 不能用 `sht` 前缀去匹配 token，新旧 token 格式不同 |

### P3. 读回超链接单元格的格式（已确认，非 bug）

- `valueRenderOption=ToString` 时，超链接单元格读回的是链接文本；`Formula` 时读回 `[{"type":"url","text":...,"link":...}]`
- 脚本写超链接时 `text` 与 `link` 都用链接本身，去重依赖这一点
- 真机验证：同数据二次同步为 `updated=3, appended=0`，没有重复行

## 二、浏览器操作（ego-browser）

### B1. 创建应用后权限不立即生效

- 开通权限、添加机器人能力后，页面顶部提示「应用发布后，当前配置方可生效」
- 必须「创建版本 → 确认发布」；免审核，可用范围只有所有者时自动通过
- 发布按钮会转圈数秒，状态变为「已发布」才算完成

### B2. 机器人能力是「添加文档应用」的前提

- 没有机器人能力，分享面板里搜不到应用
- 「添加」按钮第一次点击只转圈、无变化，需等几秒再点一次，左侧菜单出现「机器人」才算成功

### B3. 点击坐标过期，点到了屏幕外

- 现象：版本页「保存」点击后无任何反应
- 原因：先 `evaluate` 取了按钮坐标并滚动，之后才点击，坐标是滚动前的（y=1321，超出视口）
- 做法：滚动后重新取坐标再点；或截图确认按钮位置后用截图坐标

### B4. 页面骨架屏

- 开发者后台、版本页首次进入会停在灰色骨架屏 5–15 秒，此时取快照和 `innerText` 几乎为空
- 做法：先 `waitForTimeout`，或轮询等关键文字出现，不要据此判断页面异常

### B5. App Secret 的三个图标

- 位置：`/baseinfo` 的「App Secret」行右侧，依次是显示、复制、重置，只有 `svg`、没有文字
- 第一次点了第一个图标没有显示明文；点第二个才显示
- 最右侧是「重置」，点错会让旧 Secret 失效，务必避开
- 读取明文后直接在脚本里写入 `~/.zshrc` 的环境变量，不打印到对话（先 `cp` 备份 `.zshrc`，验证通过后备份移入废纸篓）
- 验证只打印长度或打码结果，例如 `zsh -ic 'echo ${#FEISHU_APP_SECRET}'`
- 终端新开才有变量；已经在运行的进程（包括当前会话的 shell）拿不到，测试时用 `zsh -ic '<命令>'`

### B6. 权限弹窗里的勾选

- 搜索 `sheets:spreadsheet` 会出 7 项（含 `:create`、`:read`、`:readonly`、`:write_only`、`.meta:read` 等）
- 只勾第一项；用 DOM 读 checkbox 状态时第 0 个是「全选」，容易看错行，必须以截图为准

### B7. 修改表格标题没生效

- 点标题后用 `ControlOrMeta+a` 再输入，标题没变，且界面随后出现「加载中」
- 风险：焦点不在标题输入框时，键入会写进单元格；本次回读确认 A1 未被污染（表头正常写入 A1）
- 做法：改标题前先截图确认进入编辑态，或手动改；标题不影响写入

### B8. 新建表格是模板弹窗

- 「新建 → 表格」不会直接创建，而是弹出模板选择，要再点「新建空白表格」
- 真正创建的表格在新标签页打开（ego-browser 里是 popup，标签 `p2`）
