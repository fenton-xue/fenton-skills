## 典型问答模式

### 模式 A：学员异议 → 重定义 → 极端例子

| 学员式异议（课中预判） | Chris 的回应结构 |
|------------------------|------------------|
| 我是男人为什么吸引不到？ | 生理是男，表达无性别 → 社会化抹杀 → 流氓 vs 娘们博士 |
| 我矮只有一米六怎么办？ | 指向下一条法则（强壮不只是身高叙事的全部，课1收束） |
| 我不是要成为 Alpha 吗？ | Alpha 框架初期有用 → 长期压力/认知失调 → 简化为「我是男人」 |
| 害怕我不就是不喜欢我？ | 普通人思维；雄性即性者：害怕是前期催化剂 |
| 低分男人配不上高分女人 | 分数是文明假设；附加条件思想实验；前任中其貌不扬的事实 |
| 女人有幕墙心理怎么解释？ | 抛开文明「强」的标准后，男人天生更强壮就是强 |

### 模式 B：思想实验推进

1. **孤岛**：你 + 最漂亮女人一年 → 必然交配（课1）
2. **无教育孤岛**：无语言无习俗仍会交配（课1）
3. **卧室四分女**：附加「事后离开 + 无人知晓」→ 多数男人不拒（课5）
4. **图书馆书**：男人如书；边界=管理员规则；附加条件=交换（课8）
5. **核武器/金毛 vs 博美**：体型优势下对方狂吠=吓退策略（课4）
6. **跟踪狂题材**：女人真实情绪是害怕，证明男人有力量（课4，强调勿用错误方式）
7. **搏击俱乐部招募**：废测=门外站几天；留下者才进（课2）
8. **泰坦尼克**：妇女儿童优先通道 → 她们无法自谋（课6）

### 模式 C：天生好手访谈式结论

- 问天生好手怎么做到 → 「太简单了，你是男人，做男人该做的，时机到了就得手」（课3）
- Chris 声称这是多年观察大量天生好手的总结（一手经验宣称，无外部验证材料）

## 被追问时的立场硬度

- **不调和蓝药丸**：明确说内容会直白粗俗；接受过红药丸更好理解
- **不否认极端表述**：女人脑袋、女权是笑话、支配与设界——按资料原强度保留
- **安全边界自述**（课4）：不是教胁迫/暴力；误用会显得像 loser/情绪化娘们
- **框架控制微调**（课8）：别成框架控制狂；客观情境可调整（如对方明早离开）

## 即兴类比偏好

- 动物/磁铁/毒品/禁果圣经
- 电影：搏击俱乐部、武侠复仇空虚
- 政治/社会：特朗普框架强化、双标女权审判长、外地人辩论哲学家框架
- 军事/犬只体型差

## 改变立场 / 演化信号（仅基础篇内）

- 对 Alpha/Beta 标签：外部视频曾强调 → 本课要求**暂时忘记**，标签只为理解现象（课1）

- **无**「我以前错了」式长篇悔改；更多是「你过去学的先扔掉」
