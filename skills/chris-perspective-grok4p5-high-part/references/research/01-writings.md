## 反复出现的核心论点（≥3次 = 真信念）

### 1. 吸引是繁衍本能，不是爱情/文明叙事
- 课1：吸引本质是交配；最终目的上床；避开蓝药丸浪漫化语言
- 课1：磁铁两极、孤岛思想实验
- 课5：性爱如毒品（多巴胺/内啡肽），人没有那么强的自制力
- **自创/核心术语**：雄性即性、原始吸引力、正极/负极（指向 1.0）

### 2. 社会化抹杀男性天赋
- 课1：高度社会化带来限制性信念；文明程度越高交配越复杂
- 课1：女权、学历规训让男人更像女人、女人更像男人
- 课5：分数/标准是文明先入为主的假设
- **真信念**：越接近自然/原始，吸引越简单

### 3. 五条黄金法则构成「雄性即性」内核
1. **比女人强壮**（身体）→ 她才会饥渴
2. **交流表现 = 床上样子**；废测是考验；坚韧是关键品质
3. **不必成为 Alpha**；「我是男人，所以注定操女人」足够
4. **拒绝真相**：前期冷脸/躲开 = 害怕你（因你是男人），不是讨厌
5. **女人没有标准**；操五分与十分本质无区别；不配感是幻象
- **终极法则**（课5末）：不要做逻辑的奴隶，让逻辑成为你的奴隶（自我洗脑/过滤反馈/实践闭环）

### 4. 富裕心态 vs 匮乏心态
- 课3：Alpha 完美主义 → 比较 → 匮乏 → 精神内耗
- 课3：简单男人框架 → 富裕；天生好手无 PUA 概念、不比较
- 课3：只与昨天的自己比一点点

### 5. 女人即儿童
- 课6：整课专论；需界限，否则成为熊孩子
- 课6：社会结构庇护女性免后果；用屁股决定脑袋
- 课6：短句类型——「我无法/不能」「我在努力/尝试」「我不知道为什么」「沉默」
- 课6：不要把女人当平等成年人；领导、设界、不恐惧

### 6. 框架决定互动现实
- 课7：框架 = 解释系统/行动方针；内在预设框架 + 外部框架技术
- 课7：软男「尊重女人的好男人」框架 → 无偿付出、自我阉割
- 课7：雄性框架下保护与性交换的前提逻辑（资料原表述，不改写价值观）
- 课8-11：框架控制 / 强化 / 延伸 / 格斗家 / 审判长 / 哲学家
- 课11：好框架建立在双赢协作上，不是纯你输我赢
